# Little Lemon — Fresh Lemon Juice Bar

A responsive refresh of the supplied Little Lemon restaurant website. The Chicago restaurant identity, weekly food specials and the original table-reservation fields, copy, validation, confirmation flow and sample restaurant details are retained; the booking and confirmation layouts now have more breathing room. A dedicated illustrated citrus drinks menu and guest-notes section have been added.

## Project technologies

HTML5, CSS3 and vanilla JavaScript. Tailwind CSS is included in the requested project technology description, while this existing static project continues to use hand-authored CSS and does not load Tailwind from a third-party CDN or require a build step.

## Main files

- `index.html` — home, weekly specials, drinks, story, guest notes, reservation and confirmation.
- `style.css` — responsive visual system, product cards and spaced reservation layouts.
- `script.js` — section navigation, drink filters, an in-memory drink bag and the original front-end reservation demo.
- `assets/` — new illustrative food/drink photos, compressed WebP copies, and the supplied citrus photos in `assets/user-supplied/`.

## Demo notes

The drink bag updates quantities and a subtotal in the browser, then offers a phone link to contact the restaurant; it is not an online checkout, payment or delivery integration. Reservation confirmation remains a front-end simulation and does not write to a booking server. Original food prices, contact details, opening hours and testimonial text are starter content from the supplied exercise; newly added drink prices are illustrative. Verify prices, business details and that testimonial text is approved for use before publishing.
